# preprocessing/extract_all_anomaly.py

## Purpose
This module defines anomaly-injection utilities for the preprocessing pipeline. It extracts anomalous test edges and injects them back into the training/validation data so that the model can learn to cope with known attack patterns during the data preparation step.

## Responsibilities
- read the processed edge list for a client
- select the anomalous edges that belong to the test period
- normalize command lines so repeated anomalous patterns can be compared across instances
- inject anomalous patterns into the train/validation split while preserving temporal structure
- keep edge-feature rows aligned with the modified edge list

## Inputs
- a client identifier
- a dataset start time for validation/test separation
- processed CSV files stored under the client output folder
- the existing edge list and edge features generated by preprocessing_data.py

## Outputs
- modified edge list containing injected anomaly patterns
- modified edge_features.csv rows aligned with the new edge rows
- optional statistics about anomaly injection and node connectivity

## Key Components
### Functions / Classes
- normalize_cmdline:
  - Purpose: canonicalizes command-line strings by removing user-specific and volatile values such as usernames, GUIDs, IPs, temp paths, and variable IDs.
  - Inputs: raw command line string.
  - Outputs: normalized string suitable for comparing anomalous patterns.

- extract_whole_anomaly:
  - Purpose: loads the processed test edges and returns the anomalous subset.

- add_anomaly_whole_in_train_val:
  - Purpose: inserts anomalous edges into the train/validation split while keeping timing and node compatibility realistic.

- add_anomaly_nodes_in_train_val:
  - Purpose: simpler variant that reinserts anomalies using their original node structure and a sampled base timestamp.

- group_node_by_type_and_ts:
  - Purpose: groups candidate nodes by type and time window to find compatible insertion points.

- deconnect_test_anomaly / stats_test_anomaly:
  - Purpose: utilities to inspect how anomalies affect graph connectivity and dataset statistics.

### Important Workflow
1. The anomalous test edges are extracted from the processed edge list.
2. Their command lines are normalized to identify recurring patterns.
3. A subset of those anomalies is inserted into the earlier data split.
4. The edge list and edge feature table are re-sorted and reindexed to remain consistent.

## Dependencies
- pandas
- numpy
- tqdm
- utils.utils
- preprocessing.temporal_patterns (calls into this module)

## Notes
- This file is closely tied to the temporal pattern injection workflow.
- It is used to stress the training data with known abnormal relations so the downstream model sees anomalous patterns during training and validation.
- The normalization logic is intentionally aggressive to collapse noisy identifiers while preserving the underlying malicious pattern.
