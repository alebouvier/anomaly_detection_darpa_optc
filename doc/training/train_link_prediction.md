# training/train_link_prediction.py

## Purpose
This file is the main training entry point for temporal link-prediction models in the project. It loads the temporal graph data, builds the requested dynamic backbone (TGAT, GraphMixer, DyGFormer, or memory-based models), trains a binary link predictor on positive and negative edge samples, and selects the best validation checkpoint for later use.

## Responsibilities
- build the temporal training, validation, and full graph samplers from the processed data
- create negative edge samplers compatible with the chosen sampling strategy
- instantiate the selected temporal GNN backbone and a MergeLayer link predictor
- train the model in mini-batches with BCE loss over positive and negative edges
- evaluate the model on validation and inductive validation sets after each epoch
- save loss curves, logs, and the best model checkpoint under an experiment folder

## Inputs
- command-line or configuration arguments such as:
  - dataset_name, start_train, start_val, start_test, end_test
  - model_name, optimizer, learning_rate, batch_size, num_epochs, num_runs
  - negative_sample_strategy, sample_neighbor_strategy, time_scaling_factor, num_neighbors
  - inductive, calibration, anomaly_injection, device, temperature
- processed temporal graph data generated by utils.DataLoader.get_link_prediction_data
- optional 2-hop neighbor CSV when the negative sampling strategy is 2hop_neighbor

## Outputs
- experiment artifacts under experiments/{dataset_name}/{model_name.lower()}/{save_model_name}/:
  - logs/
  - saved_models/
  - loss/
- per-run CSV/PNG loss summaries, including raw and smoothed batch losses
- the best trained model checkpoint selected by EarlyStopping
- console and file logs with training and validation metrics per epoch

## Key Components
### Functions / Classes
- main(args):
  - Purpose: orchestrates the full training pipeline, including data loading, negative sampling, model creation, optimization, validation, and checkpointing.
  - Inputs: runtime arguments from the training script.
  - Outputs: logs, saved model checkpoints, and loss plots.

- get_link_prediction_data:
  - Purpose: returns node features, edge features, and train/validation/test splits for link prediction.
  - Inputs: dataset and time-window parameters.
  - Outputs: processed graph data structures that the temporal sampler and model can consume.

- get_neighbor_sampler / NegativeEdgeSampler:
  - Purpose: build temporal neighborhoods and negative edge candidates for the dynamic graph model.
  - Inputs: temporal edge data and sampling configuration.
  - Outputs: reusable samplers for training and evaluation.

- EarlyStopping:
  - Purpose: tracks validation performance and keeps the best model state.
  - Inputs: validation metrics and the model parameters.
  - Outputs: checkpoint save decisions and stopping control.

### Important Workflow
1. The script loads the temporal graph splits and initializes the training/validation neighbor samplers.
2. A model is selected from TGAT, GraphMixer, DyGFormer, or a memory-based model and wrapped with a MergeLayer link predictor.
3. For each training epoch, it samples positive and negative edges, computes source/destination temporal embeddings, applies BCE loss, and updates weights with the optimizer.
4. Validation metrics are computed after each epoch to decide whether to keep or stop training, and the loss curves are saved to disk.

## Notes
- This is the standard training workflow used for temporal graph link prediction experiments.
- Different model families require different embedding calls, but the overall training loop is consistent: compute temporal node embeddings for positive and negative edges, score both, and train on binary labels.
- For memory-based models (JODIE, DyRep, TGN), the script carefully snapshots and reloads the memory bank around validation steps so pruning and new-node evaluation remain consistent.
- The loss curves are smoothed with a median filter before plotting, and the final model is the one selected by validation metrics rather than the last epoch.
